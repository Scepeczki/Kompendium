# Kompendium

## ⬇ [Pobierz Kompendium na Windows](https://github.com/Scepeczki/Kompendium/releases/latest)

Na stronie wydania pobierz plik `Kompendium_…_x64-setup.exe` i uruchom go.
Gdy Windows pokaże „System Windows ochronił ten komputer”, kliknij
„Więcej informacji” → „Uruchom mimo to”. Kolejne wersje program pobiera sam.

---

Notatki do nauki: kafelki (definicje, twierdzenia, przykłady), ścieżki,
PDF-y i powtórki. Wszystko leży na twoim komputerze — w tym repozytorium
jest tylko program, żadnych notatek.

- Opis i plany: [VISION.md](VISION.md), [ROADMAP.md](ROADMAP.md), [SLOWNIK.md](SLOWNIK.md)
- Kod: [app/](app/) (React + TypeScript), program na Windows: [app/src-tauri/](app/src-tauri/) (Tauri)
- Nowa wersja: `cd app && npm run wydaj`
